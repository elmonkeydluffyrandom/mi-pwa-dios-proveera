# **App Name**: Dios Proveerá PWA

## Core Features:

- Product Search and Autocomplete: Implement a search field with autocomplete functionality to quickly find products.
- Sales Registration: Record sales transactions with product selection, quantity input, and automatic price calculation.
- Inventory Management: Allow users to view existing products, add new products (name, price, category), and store information locally.
- Local Storage Persistence: Utilize localStorage to store inventory and sales data for offline functionality.
- Intelligent Product Suggestions: Use a generative AI tool that takes current sales into account and will suggest new products the store owner might wish to stock, drawing from existing product information when appropriate.

## Style Guidelines:

- Primary color: Soft green (#A7D1AB) for a calm and natural feel, in keeping with the application name.
- Background color: Very light green (#F0FAF2), subtly tinted with the same hue as the primary color for a clean backdrop.
- Accent color: Light blue (#9AC6D1), an analogous color for interactive elements and buttons.
- Body and headline font: 'PT Sans', a humanist sans-serif font that combines a modern look and a little warmth or personality.
- Use clear, intuitive icons to represent product categories and actions.
- Design a responsive layout that adapts to different screen sizes, ensuring usability on both mobile and desktop devices.
- Incorporate subtle animations for user interactions, such as adding products to the sale or updating the inventory.
